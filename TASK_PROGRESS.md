| D. Поза | DONE | MoveNet INT8 и TensorFlow Lite 2.16.1 собраны для API 19. Модель нашла суставы на реальной фотографии на физическом ARMv7 и x86 AVD. Поток камеры через MoveNet проверен на AVD. PoseNet остаётся резервом. |
| E. Подсчёт | DONE | Девять модульных тестов прошли. Покрыты полные и неполные циклы, потери суставов, дребезг, геометрия и даты. Практическая калибровка обоих упражнений на живом человеке остаётся на этапе H. |
| F. Интерфейс | DONE | В APK 1.1 перенесён новый дизайн тренировки, календаря и статистики. Для экранов от 720 dp используется двухколоночная компоновка. Кнопка переключения камеры находится в заголовке предпросмотра. Поворот и возврат из фона проверены на AVD. |
| G. Хранение | DONE | SQLite сохраняет подход один раз, читает записи после повторного открытия базы, выделяет тренировочные даты и считает суммы по типам упражнений. Инструментальные тесты прошли на обеих платформах. |
| H. Приёмка | IN PROGRESS | Шесть инструментальных тестов прошли на Tango и AVD. На Tango подтверждён поток через MoveNet и измерена производительность. Практическая проверка живых подходов остаётся открытой. |
